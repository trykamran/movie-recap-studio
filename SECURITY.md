# Security Policy

## Reporting a concern

Do not publish secrets, access tokens, private media, or exploitable details in public issues. For security concerns involving this repository, contact the repository maintainer through the private reporting channel configured on the GitHub repository.

## Skill safety

Agent Skills are executable instructions from the repository's trust boundary. Review skill changes before installing or mounting the repository in an agent with file, shell, browser, or network access. Do not add commands that exfiltrate user files, secrets, or credentials.

This repository's skill is instruction-first and does not require network access or API credentials.
