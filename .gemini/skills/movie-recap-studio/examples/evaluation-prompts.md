# Skill evaluation prompts

These prompts are designed to test behavior, not to prescribe one movie's content.

## E01 — Short mode setup
**Prompt:** "Use Movie Recap Studio. I want a 90-second English movie recap."

**Pass criteria:**
- Selects short mode.
- Asks only the next missing setup question.
- Eventually requests the complete SRT.
- Does not create a long-video Shorts extraction stage.

## E02 — Long mode setup
**Prompt:** "I want a 20-minute full explanation of a 2.5-hour movie."

**Pass criteria:**
- Treats it as one continuous complete movie explanation.
- Does not split it into episodes.
- Asks for language and complete SRT as needed.

## E03 — Script is generated by the agent
**Prompt:** "The story analysis is approved. I choose Mystery & Suspense."

**Pass criteria:**
- Immediately writes the full narration.
- Does not ask the user to provide a script.
- Places only spoken words in one copy-ready code block.

## E04 — Actual TTS is the source of truth
**Prompt:** "Here is my final TTS audio. Read it and find the scenes."

**Pass criteria:**
- Reads/transcribes the actual audio.
- Segments the spoken words by voiceover time.
- Does not compare against or correct the earlier draft unless explicitly requested.

## E05 — Independent SRT re-read
**Prompt:** "Now map this narration to the movie and give me Movie Recap timestamps."

**Pass criteria:**
- Re-reads the complete SRT in a separate pass.
- Maps each spoken beat to relevant SRT evidence and candidate source timecodes.
- Does not select scenes by keyword matching alone.
- Does not invent source timestamps.

## E06 — Timeline separation
**Prompt:** "The original scene is at 00:42:10, and it appears at 07:30 in my recap. Give me Shorts ranges."

**Pass criteria:**
- Recognizes 00:42:10 as source movie time and 07:30 as master video time.
- Uses master-video time for Shorts extraction.

## E07 — No SRT available
**Prompt:** "Write exact source timestamps, but I don't have the SRT."

**Pass criteria:**
- Explains exact source timestamps cannot be grounded.
- Requests SRT or an accessible source video/timecoded transcript.
- Does not fabricate timecodes.

## E08 — Final rendered video review
**Prompt:** "Review this completed recap video."

**Pass criteria:**
- Uses available media inspection capabilities.
- Distinguishes sampled-frame review from full playback.
- Gives concrete, prioritized observations.

## E09 — English onboarding on first invocation
**Prompt:** "Use Movie Recap Studio."

**Pass criteria:** English welcome; asks only Long vs Short; does not claim installation itself triggered a message.

## E09 — English first-run greeting
**Prompt:** "Use Movie Recap Studio. Let's start."

**Pass criteria:**
- Welcomes the user in English.
- Asks only the long-form versus short-form question.
- Does not claim that installing the skill sent the message automatically.

## E10 — Companion app release boundary
**Prompt:** "Where can I download the mobile and desktop app?"

**Pass criteria:**
- Explains the Movie Recap app is separate from the skill.
- Does not invent a release asset or claim unverified builds exist.
- Refers to verified GitHub Releases when available.
